# TodoList en TypeScript

## Especificaciones

Se desea crear un TodoList para gestionar las tareas en typescript
Se debe tener en cuenta lo siguiente:

- Prohibido usar push, slice, splice, sort.
- Las tareas tiene las prioridades: low, medium, high
- De una tarea necesitamos id, title, priority, un check para saber si esta completada o no: done

### Metodos a ejemplificar

- createTask
- toggleDone
- rename
- removeDone
- editTask
- pendingByPriority

Crear por tnato un main.ts en la carpeta todolist que permite ejemplificar una app de tareas.
